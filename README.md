## 📋 Sobre o Projeto

O **Projeto Banco** é uma aplicação robusta que simula operações bancárias essenciais, como gerenciamento de contas, saques, depósitos e transferências. O objetivo principal deste projeto é demonstrar o domínio de **Programação Orientada a Objetos (POO)**, tratamento de exceções e estruturação de projetos em Java.

### 🚀 Roadmap de Evolução
O projeto está em constante desenvolvimento. Os próximos passos incluem:
- [ ] **Desenvolvimento de API REST:** Evolução do projeto para disponibilizar endpoints da aplicação (planejado).
- [ ] **Persistência de Dados:** Integração com banco de dados (ex: PostgreSQL/MySQL).
- [ ] **Testes Automatizados:** Implementação de testes unitários com JUnit e Mockito.

## 🛠️ Tecnologias e Arquitetura

- **Linguagem:** Java
- **Estrutura:** Separação de responsabilidades em pacotes lógicos (`model`, `exception`, `main`).
- **Padrões:** Aplicação de conceitos de Clean Code e encapsulamento.

## ⚙️ Funcionalidades Atuais

- Criação e gerenciamento de contas bancárias.
- Operações financeiras fundamentais (Saque, Depósito e Transferência).
- Validação de regras de negócio rigorosas (ex: saldo insuficiente).
- Lançamento de exceções customizadas para tratamento de erros.

## 💻 Como Executar Localmente

Pré-requisitos: JDK instalado em sua máquina.

1. Clone este repositório:
```bash
git clone https://github.com/gucarneiro/projeto-banco.git
```
2. Abra o diretório do projeto na sua IDE de preferência (ex: IntelliJ IDEA).
3. Navegue até o pacote `src/com/gucarneiro/banco/main` e execute a classe correspondente.
